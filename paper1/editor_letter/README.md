# HKUST-GZ Letter Template

A professional LaTeX letter template for The Hong Kong University of Science and Technology (Guangzhou).

## Quick Start

1. Edit the customizable variables at the top of `main.tex`
2. Replace the letter content with your own text
3. Compile with `pdflatex main.tex`

## Features

- Professional header with logo and contact info
- Customizable sender/recipient information
- Multi-page support with headers/footers
- Optional background watermark
- Clean, modern design

## Required Files

- `main.tex` - Main template file
- `HKUSTGZ.png` - University logo
- `signature.png` - Your signature (optional)
- `background.png` - Background watermark (optional)

## Usage

Please simply modify the variables at the top of `main.tex` and replace the sample content with your letter text. The template handles formatting automatically.
